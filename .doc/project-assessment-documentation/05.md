### 5. UI/UX Design, Accessibility & Responsive Architecture

#### 5.1 Responsive Split-Pane Mechanics

TraceDiary executes dynamic layout adaptations without relying on external UI framework routers. Viewport dimensions are monitored using a native `window.matchMedia` query within the presentation layer. When the viewport falls below the 768px Bootstrap breakpoint, the application transitions from a dual-pane desktop configuration to a single-pane mobile view. 

This state is evaluated and applied through the `applyResponsiveLayout()` and `showDetailViewMobile()` functions. Rather than re-rendering DOM elements, the logic selectively applies Bootstrap's display utility class (`d-none`) to toggle visibility between the list and detail containers. 

```javascript
function showDetailViewMobile() {
  if (!MOBILE_QUERY.matches) {
    return;
  }
  listView.classList.add("d-none");
  detailView.classList.remove("d-none");
  window.scrollTo({ top: 0 });
}
