(async, inner) handleEntryFormSubmit(event) → {Promise.<void>}

Handle the entry form submission for both creating and updating entries. Determines create vs update from `entryIdInput.value`, validates required fields, and either warns (and returns) or dispatches the appropriate API call. On success: closes the modal, refreshes the list (clearing filters on create so the new row is visible), updates the detail pane on edit, and shows a toast. On failure: logs and shows an error dialog. The submit button is disabled for the duration to prevent double submits.
